 # Змейка (Snake Game)

Классическая аркадная игра «Змейка» на HTML5 Canvas с дополнительными возможностями.

## 🚀 Запуск
Откройте `index.html` в современном браузере (рекомендуется Chrome) через локальный сервер (например, Live Server в VS Code).

## 🎮 Управление
- По умолчанию: стрелки (↑ ↓ ← →).
- **Настройка клавиш**: нажмите на текущую клавишу в блоке «Настройка клавиш», затем нужную клавишу на клавиатуре – она сохранится автоматически.

## ✨ Функции
- Движение, поедание еды, рост змейки и увеличение скорости.
- Препятствия (включаются чекбоксом) — случайные кластеры из нескольких клеток, столкновение с которыми завершает игру.
- Таймаут еды: если не съесть еду вовремя, она начинает мигать и исчезает, появляясь в новом месте.
- Три уровня сложности (влияют на начальную скорость и темп ускорения).
- Сохранение рекорда и пользовательских клавиш в localStorage.
- Кнопки: Новая игра (старт с сохранением рекорда), Пауза/Продолжить, Сброс (обнуляет рекорд).
- Адаптивный размер поля (≈80% экрана).

## 📁 Структура
- `index.html` – разметка
- `css/style.css` – стили
- `js/constants.js` – конфигурация игры
- `js/storage.js` – работа с localStorage
- `js/input.js` – настройка клавиш (клик + нажатие)
- `js/game.js` – основная логика (змея, еда, препятствия, цикл)
- `js/main.js` – инициализация и UI
